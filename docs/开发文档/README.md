# CodeRisk 最终设计文档包

本目录包含 CodeRisk MVP 的最终设计基线。文档描述目标设计与验收要求，**不代表业务代码已经实现或测试已经通过**。

## 文档目录与阅读顺序

1. `项目总纲.md`：项目定位、范围、协作和阶段状态。
2. `产品需求与业务规则.md`：用户流程、业务规则、验收目标。
3. `总体架构与技术决策.md`：服务边界、异步架构、可靠性和技术取舍。
4. `数据库与任务状态设计.md`：核心实体、状态机、重试、恢复、保留策略。
5. `系统接口与服务契约.md`：公开 API、内部回调、Kafka/Celery 契约。
6. `Agent工作流与证据规范.md`：多 Agent 分工、报告 schema、证据校验、评测。
7. `认证权限与安全设计.md`：登录、用户隔离、输入安全、密钥、日志和数据删除。
8. `开发实施与验收计划.md`：从仓库检查到最终演示的分阶段路线。
9. `设计决策与变更记录.md`：关键决策速查与偏差管理。
10. `最终交叉审查报告.md`：文档一致性检查结果和仍需通过实现/测试验证的事项。

## 实施原则

- Go + PostgreSQL 是业务事实来源；Python Agent 不直接写业务数据库。
- 先检查真实仓库，再按切片实施；不要一次性生成整套代码。
- 默认参数是可校准基线，不是实测性能承诺。
- 每个阶段必须提供实际测试证据；未运行的测试不得标记通过。
